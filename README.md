
# E-Commerce 3NF Normalization Project

This project redesigns a broken e-commerce schema to follow Third Normal Form (3NF).

## Improvements
- Removed multi-valued columns
- Added proper entity separation
- Added primary keys and foreign keys
- Reduced redundancy
- Improved scalability

- schema/broken_schema.sql
